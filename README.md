# ⚡ Codex CLI Termux Manager

A professional interactive manager for installing, updating, repairing, configuring, diagnosing, and launching Codex CLI on Android Termux.

## ✨ Features

- 🚀 Install Codex CLI
- 🔧 Repair Codex installations
- ⬆️ Update Codex
- 🤖 AgentRouter configuration
- 🔑 Secure API key input
- 🔍 Automatic AgentRouter model discovery
- ✍️ Manual model ID support
- 🔄 Refresh available models
- 🩺 Systematic diagnostics
- 🌐 Network and provider reachability checks
- 🔌 WebSocket diagnostics
- 🖥️ Terminal environment checks
- 🛠️ Common fixes
- 📊 Status and configuration viewer
- ▶️ Launch Codex directly with `codex`
- 🗑️ Uninstall Codex
- 📱 ARM64 / x64 native package repair
- 🎨 Professional Termux UI
- 🌈 Color and `NO_COLOR=1` support
- 📦 Interactive menu and direct CLI commands

---

## 📱 Requirements

- Android
- Termux
- Internet connection

The manager can install required packages such as:

- `curl`
- `nodejs`
- `npm`
